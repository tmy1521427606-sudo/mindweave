# 知脉 MindWeave

> 把每天的信息，沉淀成自己的认知。

知脉是一款本地运行的个性化认知学习应用。它把近期新闻、跨领域知识和个人反馈连接起来，帮助读者持续理解电商、Agent、数据、金融与科技等方向，而不只是浏览信息。

## 主要功能

- 浏览今天、昨天及往期日报，按关键词、主题和来源筛选
- 查看新闻事实、来源、影响、跨领域联系与学习建议
- 收藏、跟踪，并通过“更多同类”“减少推荐”“不感兴趣”等反馈调整内容
- 将新闻归纳为可回溯的知识卡片和主题 Wiki
- 使用豆包 Agent 优先检索本地知识库，必要时通过 Tavily 联网核实
- 点击后按昨日优先、近 7 天补充的规则筛选最多 20 条；首批 5 条先发布，其余内容继续生成，并保留同日多个版本
- 导出不含 API 密钥的本地知识数据

## 本地启动

运行环境：Windows PowerShell、Node.js 22 或更高版本。

```powershell
git clone https://github.com/tmy1521427606-sudo/mindweave.git
cd mindweave
.\start.ps1
```

脚本会自动选择本机端口、打开浏览器，并在窗口中显示模型、联网搜索和知识库状态。关闭 PowerShell 窗口或按 `Ctrl+C` 即可停止服务。

不配置模型也能使用日报、筛选、反馈、历史搜索和知识库浏览。

## 配置学习 Agent 与日报生成（可选）

在启动前设置以下环境变量：

```powershell
$env:ARK_API_KEY = '你的火山方舟 API Key'
$env:DOUBAO_CHAT_MODEL = '你的豆包推理接入点 ID'
$env:DOUBAO_EMBEDDING_MODEL = '你的向量模型接入点 ID' # 可选
$env:TAVILY_API_KEY = '你的 Tavily API Key'            # 生成日报时必需
.\start.ps1
```

更完整的配置和检索行为说明见 [本地 Agent 配置](docs/local-agent-setup.md)。

打开网站不会调用付费接口。只有点击首页顶部的“生成今日日报”后，系统才会搜索并调用豆包；选项与昨日点评均可留空。生成并校验出首批 5 条后会立即发布，页面可以先阅读；本地 Node 服务会在后台继续补充，新增有效内容完成后发布第 2 版。关闭浏览器不影响后台补充，但 PowerShell、`start.ps1` 对应的 Node 进程必须保持运行，电脑也不能休眠或关机。单个模型批次连续失败时会跳过，无效条目不会进入数量统计或日报。整个任务达到 10 分钟后保留已经发布的版本。当天已有日报时，可以选择“重新生成完整版本”或“只补充新内容”，旧版本仍可回看。

GLM 返回的条目会按完整字段结构校验；格式不完整时只纠正重试一次。页面会显示脱敏后的模型格式问题和已纠正批次数，失败日志只记录原因分类与数量，不保存模型原文或 API Key。

## 数据与隐私

- 新闻样例保存在 `data/`，个人反馈和知识卡片保存在本机 `var/cognitive-daily.sqlite`
- 新日报按 `data/YYYY-MM-DD-vN.json` 保存，`data/index.json` 只指向当前版本
- SQLite 数据库、日志文件和 `.env` 已被 Git 忽略，不会随正常提交上传
- API Key 只由本地 Node.js 服务读取，不会发送到浏览器或包含在知识导出中
- 当前版本面向单机个人使用，不包含账号、跨设备同步或多人共享

## 当前阶段

这是用于验证“个性化筛选 + 跨领域关联 + 知识沉淀 + 学习 Agent”的本地原型。日报只在你点击生成时更新；生成开始后可在本地服务仍运行时继续后台补充，但关闭程序后不能继续，也不会自动提交或推送 GitHub。未来部署服务器后再增加每天 8 点前预先收集的定时任务。确认内容后需手动执行 `git add`、`git commit` 和 `git push`。
